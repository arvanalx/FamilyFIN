## 1. Εκκίνηση της Εφαρμογής

Η εφαρμογή τρέχει μέσω Python web server.

### Εκκίνηση server

```bash
python3 FamilyFIN/server.py
```

Στη συνέχεια ανοίξτε τον browser στη διεύθυνση:

```
http://localhost:8765
```

### Αποθήκευση δεδομένων

Τα δεδομένα αποθηκεύονται **αυτόματα** σε κάθε αλλαγή:
- **Κύρια αποθήκευση:** βάση δεδομένων SQLite (`familyfin.db`) στον φάκελο της εφαρμογής — αξιόπιστη, ανθεκτική σε σφάλματα
- **Εφεδρική αποθήκευση:** `localStorage` του browser (χρησιμοποιείται αν ο server δεν τρέχει)

#### Αυτόματη μετάβαση από data.json

Αν υπάρχει αρχείο `data.json` από παλαιότερη έκδοση, κατά την **πρώτη εκκίνηση** ο server το εισάγει αυτόματα στη βάση SQLite και στη συνέχεια το διαγράφει. Η διαδικασία γίνεται μία φορά χωρίς καμία ενέργεια από τον χρήστη.

> ⚠️ Αν ανοίξετε το `index.html` απευθείας (χωρίς server), τα δεδομένα αποθηκεύονται μόνο στο localStorage και μπορεί να χαθούν αν καθαρίσετε τα δεδομένα του browser.

## 3. Λειτουργία Απορρήτου (Privacy Mode)

Το κουμπί **👁️** στην επάνω δεξιά γωνία ενεργοποιεί τη **Λειτουργία Απορρήτου** — χρήσιμη όταν θέλετε να δείξετε κάτι από την εφαρμογή σε τρίτο πρόσωπο χωρίς να αποκαλύψετε τις οικονομικές αξίες.

### Πώς λειτουργεί

| Κατάσταση | Εικονίδιο | Εμφάνιση κουμπιού |
|-----------|-----------|-------------------|
| **Κανονική** | 👁️ | Διαφανές, με περίγραμμα |
| **Απόρρητο** | 🙈 | Μπλε γεμιστό — υπενθυμίζει ότι τα ποσά είναι κρυφά |

Πατήστε μία φορά για ενεργοποίηση, ξανά για απενεργοποίηση. Η εναλλαγή γίνεται με **ομαλό animation θολώματος** (0.3 δευτερόλεπτα).

### Τι αποκρύπτεται

Σε **όλες τις σελίδες** θολώνουν αυτόματα:

| Ενότητα | Στοιχεία που αποκρύπτονται |
|---------|--------------------------|
| **Γρήγορη ματιά** | Υπόλοιπα λογαριασμών (Σήμερα/Πρόβλεψη), Έσοδα/Έξοδα/Υπόλοιπο μήνα, σύνολα καρτών, γραφήματα |
| **Κινήσεις** | Ποσά γραμμών πίνακα, σύνοψη Έσοδα/Έξοδα/Υπόλοιπο |
| **Έσοδα** | Μηνιαία & ετήσια σύνοψη, ποσά γραμμών |
| **Πιστωτικές Κάρτες** | Τρέχον υπόλοιπο, δόσεις/μήνα, μηνιαίες κινήσεις, ποσά κινήσεων |
| **Δόσεις** | Μηνιαία επιβάρυνση, εναπομείναντα ποσό, μηνιαία δόση κάθε δόσης |
| **Συνδρομές** | Μηνιαίο/ετήσιο κόστος, ποσό κάθε συνδρομής |

> 💡 Τα **ονόματα** λογαριασμών, κατηγορίες, περιγραφές και ημερομηνίες παραμένουν ορατά — αποκρύπτονται **μόνο τα νούμερα σε €**.

> ℹ️ Η κατάσταση απορρήτου **δεν αποθηκεύεται** — επαναφέρεται αυτόματα στο κανονικό όταν ανανεώσετε τη σελίδα.

## 4. Γρήγορη Ματιά (Dashboard)

Η αρχική σελίδα παρέχει μια ολοκληρωμένη εικόνα της οικονομικής κατάστασης.

### 4.1 Υπόλοιπα Λογαριασμών

Πίνακας με δύο στήλες για κάθε λογαριασμό:

- **Σήμερα:** Το τρέχον υπόλοιπο όπως έχει καταχωρηθεί στις Ρυθμίσεις (συμπεριλαμβάνει τις ολοκληρωμένες κινήσεις)
- **Πρόβλεψη:** Υπολογισμένο υπόλοιπο που συνυπολογίζει **μόνο τις μη-ολοκληρωμένες κινήσεις** (έως το τέλος του επόμενου μήνα)

> 💡 Η μέγιστη ημ/νία "Πρόβλεψη" υπολογίζεται αυτόματα ως η πιο πρόσφατη ημερομηνία κίνησης, με ανώτατο όριο το τέλος του επόμενου μήνα.

Οι τραπεζικοί λογαριασμοί εμφανίζουν το όνομα της τράπεζας σε παρένθεση με μικρότερα γράμματα (π.χ. *Μισθοδοσίας (Alpha Bank)*).

### 4.2 Μεταβολές Λογαριασμών

Ραβδόγραμμα που απεικονίζει γραφικά τα υπόλοιπα όλων των λογαριασμών:
- **Έντονο χρώμα** = τρέχον υπόλοιπο (σήμερα)
- **Ανοιχτό χρώμα** = μελλοντικό υπόλοιπο

Κάθε λογαριασμός χρησιμοποιεί το ίδιο χρωματικό ζεύγος (π.χ. σκούρο μπλε / ανοιχτό μπλε) για εύκολη αναγνώριση. Διαθέσιμες προβολές: **Σύγκριση** (Σήμερα vs Πρόβλεψη) και **Μεταβολή** (ποσοστιαία διαφορά).

### 4.3 Υπόλοιπα ανά Ημέρα

Γραμμικό γράφημα που δείχνει πώς διαμορφώνεται το υπόλοιπο κάθε λογαριασμού ημέρα-ημέρα από σήμερα έως την τελευταία ημερομηνία πρόβλεψης:

- Ξεκινά από το **τρέχον υπόλοιπο** (Ρυθμίσεις) για κάθε λογαριασμό
- Συνυπολογίζει μόνο τις **μη-ολοκληρωμένες κινήσεις** από σήμερα έως την πρόβλεψη
- Ένα **dot** σε κάθε ημερομηνία όπου υπάρχει κίνηση (hover για ποσό)
- Διακεκομμένη γραμμή **"Σήμερα"** ως σημείο εκκίνησης
- Καταλήγει ακριβώς στο ποσό **Πρόβλεψης** των ΥΠΟΛΟΙΠΑ ΛΟΓΑΡΙΑΣΜΩΝ

### 4.4 Ισοζύγιο Κινήσεων Μήνα

Σύνοψη για τον **τρέχοντα μήνα** (χωρίς μεταφορές λογαριασμών):
- **Έσοδα:** Σύνολο εσόδων από κινήσεις τύπου "Έσοδο"
- **Έξοδα:** Σύνολο εξόδων από κινήσεις τύπου "Έξοδο"
- **Υπόλοιπο:** Διαφορά Εσόδων − Εξόδων (πράσινο αν θετικό, κόκκινο αν αρνητικό)

### 4.5 Υπόλοιπα Πιστωτικών Καρτών (σύνοψη)

Για κάθε κάρτα εμφανίζεται:
- **Σύνολο μήνα** (έντονο κόκκινο) = κινήσεις τρέχοντος μήνα + μηνιαίες δόσεις
- **xxx,xx € κινήσεις/μήνα** — κινήσεις του τρέχοντος μήνα
- **xxx,xx € δόσεις/μήνα** — μηνιαίο ποσό ενεργών δόσεων (εμφανίζεται μόνο αν > 0)

### 4.6 Έξοδα ανά Κατηγορία

**Donut chart** που δείχνει την κατανομή εξόδων του τρέχοντος μήνα από:
- Κινήσεις λογαριασμών (εξαιρούνται κινήσεις με κατηγορία "Κάρτες")
- Κινήσεις πιστωτικών καρτών
- Μηνιαίες δόσεις (ενεργές)

Κάθε τμήμα δείχνει: κατηγορία, ποσοστό (%) και ποσό σε €. Στο κέντρο εμφανίζεται το **συνολικό ποσό εξόδων**.

### 4.7 Έξοδα ανά Μήνα

**Κατακόρυφο bar chart** που εμφανίζει τα συνολικά έξοδα για κάθε μήνα του επιλεγμένου έτους.

**Επιλογή έτους:** Dropdown πάνω δεξιά στην κάρτα — προεπιλογή το τρέχον έτος. Τα διαθέσιμα έτη εξάγονται αυτόματα από τα δεδομένα σας.

**Λογική υπολογισμού** (ίδια με §4.6):
- Κινήσεις λογαριασμών τύπου Έξοδο, εξαιρουμένων μεταφορών και κατηγορίας "Κάρτες"
- Κινήσεις πιστωτικών καρτών
- Μηνιαίες δόσεις ενεργές — μόνο για τον **τρέχοντα μήνα**

**Χρωματική κωδικοποίηση:**
- **Μπλε** (accent): τρέχων μήνας
- **Ανοιχτό μπλε**: παρελθοντικοί μήνες
- **Γκρι**: μελλοντικοί μήνες

Το ποσό εμφανίζεται πάνω από κάθε μπάρα (εφόσον χωράει). Τοποθετήστε τον κursor πάνω σε κάθε μπάρα για tooltip με ακριβές ποσό.

### 4.8 Τελευταίες Κινήσεις

Οι 6 πιο πρόσφατες κινήσεις. Πατήστε **"Όλες →"** για να μεταβείτε στη σελίδα Κινήσεων.

## 5. Κινήσεις

Η κεντρική σελίδα καταχώρησης και παρακολούθησης **εξόδων και εσόδων** λογαριασμών.

### 5.1 Προσθήκη νέας κίνησης

Πατήστε **"+ Νέα Κίνηση"** (επάνω δεξιά στη σελίδα Κινήσεων).

Συμπληρώστε τα πεδία:

| Πεδίο | Υποχρεωτικό | Περιγραφή |
|-------|------------|-----------|
| **Τύπος** | ✅ | Έξοδο ή Έσοδο |
| **Ημερομηνία** | ✅ | Ημερομηνία κίνησης |
| **Ποσό (€)** | ✅ | Θετικός αριθμός |
| **Περιγραφή** | ✅ | Σύντομη περιγραφή |
| **Κατηγορία** | — | Από τη λίστα κατηγοριών (εξόδων ή εσόδων ανάλογα με τον τύπο) |
| **Λογαριασμός** | ✅ | Ο λογαριασμός χρέωσης/πίστωσης |
| **Ολοκληρωμένη** | — | Αν η κίνηση έχει εκκαθαριστεί (βλ. §5.2) |
| **Σημειώσεις** | — | Προαιρετικό κείμενο |

> 💡 Αλλάζοντας τον **Τύπο** (Έξοδο/Έσοδο), η λίστα κατηγοριών αλλάζει αυτόματα — εμφανίζει Κατηγορίες Εξόδων ή Εσόδων αντίστοιχα.

### 5.2 Πεδίο "Ολοκληρωμένη"

Κάθε κίνηση λογαριασμού μπορεί να επισημανθεί ως **Ολοκληρωμένη**, δηλαδή ότι το χρήμα έχει πραγματικά κινηθεί στον/από τον λογαριασμό.

**Τρόποι ενεργοποίησης:**
- **Γρήγορη εναλλαγή (desktop):** Πατήστε το κουμπί **☐** (1ο στη στήλη Ενεργειών) → γίνεται **✅**
- **Από κινητό:** Πατήστε πάνω στην κίνηση → επιλέξτε **✅ Ολοκλήρωση** ή **☐ Αναίρεση Ολοκλήρωσης** στο menu ενεργειών
- **Από τη φόρμα:** Τσεκάρετε το πεδίο "Ολοκληρωμένη" κατά την προσθήκη ή επεξεργασία

**Αποτέλεσμα:**
- **Έξοδο ✅** → Αφαιρείται το ποσό από το υπόλοιπο του λογαριασμού
- **Έσοδο ✅** → Προστίθεται το ποσό στο υπόλοιπο του λογαριασμού
- Η κίνηση **εξαιρείται** από τον υπολογισμό "Πρόβλεψη" στη Γρήγορη Ματιά (έχει ήδη συνυπολογιστεί στο υπόλοιπο)

Πατώντας ξανά ✅ → ☐ αναιρείται η επίδραση στο υπόλοιπο.

> ℹ️ Κινήσεις που δημιουργούνται αυτόματα από Συνδρομές (🔄) μπορούν επίσης να επισημανθούν ως ολοκληρωμένες και να επεξεργαστούν κανονικά.

### 5.3 Επεξεργασία / Διαγραφή κίνησης

**Desktop** (στήλη Ενεργειών):
- **☐ / ✅** — Εναλλαγή κατάστασης "Ολοκληρωμένη" (επηρεάζει το υπόλοιπο αμέσως)
- **✏️** — Ανοίγει τη φόρμα επεξεργασίας (διαθέσιμο για όλες τις κινήσεις εκτός από μεταφορές ↔️)
- **🗑️** — Ζητά επιβεβαίωση και διαγράφει την κίνηση (αν ήταν ολοκληρωμένη, αναιρείται αυτόματα η επίδραση στο υπόλοιπο)

**Κινητό** (πάτημα σε γραμμή κίνησης):
- Ανοίγει menu ενεργειών με επιλογές: **Ολοκλήρωση / Αναίρεση**, **Επεξεργασία**, **Διαγραφή**

### 5.4 Αντιγραφή εσόδου στον επόμενο μήνα

Στις κινήσεις τύπου **Έσοδο**, εμφανίζεται το εικονίδιο **📋**. Πατώντας το, δημιουργείται αυτόματα αντίγραφο της κίνησης με ημερομηνία **+1 μήνα** από την αρχική.

> Χρήσιμο για επαναλαμβανόμενα έσοδα (μισθός, σύνταξη κ.λπ.).

### 5.5 Φιλτράρισμα & Αναζήτηση

Επάνω από τον πίνακα υπάρχουν 4 φίλτρα:

| Φίλτρο | Λειτουργία |
|--------|-----------|
| **Μήνας** | Εμφανίζει κινήσεις συγκεκριμένου μήνα (προεπιλογή: τρέχων μήνας) |
| **Λογαριασμός** | Φιλτράρει ανά λογαριασμό (μόνο οι λογαριασμοί από τις Ρυθμίσεις) |
| **Κατηγορία** | Φιλτράρει ανά κατηγορία εξόδου/εσόδου |
| **🔍 Αναζήτηση** | Αναζήτηση ελεύθερου κειμένου στην περιγραφή |

Τα φίλτρα **συνδυάζονται** μεταξύ τους. Κάτω από τα φίλτρα εμφανίζεται η γραμμή σύνοψης:

- **Έσοδα** (πράσινο) | **Έξοδα** (κόκκινο) | **Υπόλοιπο**

### 5.6 Ταξινόμηση

Πατήστε οποιαδήποτε επικεφαλίδα στηλών (**Ημερομηνία ↕**, **Περιγραφή ↕**, **Ποσό ↕**) για ταξινόμηση. Δεύτερο πάτημα αντιστρέφει τη σειρά.

### 5.7 Μεταφορά Χρημάτων μεταξύ Λογαριασμών

Πατήστε **↕ Μεταφορά** (δίπλα στο "+ Νέα Κίνηση") για να ανοίξετε τη φόρμα μεταφοράς. Συμπληρώστε:

| Πεδίο | Περιγραφή |
|-------|-----------|
| **Ημερομηνία** | Ημερομηνία της μεταφοράς |
| **Ποσό** | Το ποσό που μεταφέρεται |
| **Από Λογαριασμό** | Ο λογαριασμός που χρεώνεται |
| **Σε Λογαριασμό** | Ο λογαριασμός που πιστώνεται |
| **Σημειώσεις** | Προαιρετική περιγραφή |

**Αποτέλεσμα:** Δημιουργούνται αυτόματα **δύο συνδεδεμένες κινήσεις** — μία χρέωση (Έξοδο) στον λογαριασμό προέλευσης και μία πίστωση (Έσοδο) στον λογαριασμό προορισμού. Και οι δύο επισημαίνονται με το εικονίδιο ↔️ και την κατηγορία **Μεταφορά** (μοβ).

**Ολοκληρωμένη μεταφορά:** Αν κατά την καταχώριση τσεκάρετε το πεδίο **Ολοκληρωμένη**, τα υπόλοιπα και των δύο λογαριασμών ενημερώνονται αμέσως. Εναλλακτικά, μπορείτε να ολοκληρώσετε/αναιρέσετε αργότερα πατώντας **☐ / ✅** (desktop) ή πατώντας στην κίνηση ↔️ (κινητό) — η ενέργεια εφαρμόζεται **και στις δύο** πλευρές ταυτόχρονα.

> ⚠️ Η διαγραφή **μίας** πλευράς διαγράφει **αυτόματα και τις δύο** και αναιρεί τις αλλαγές στα υπόλοιπα.

### 5.8 Αναφορά PDF

Πατήστε **📄 Αναφορά** (κάτω από τα κουμπιά Μεταφορά / Νέα Κίνηση) για να δημιουργήσετε αναφορά με τις κινήσεις που εμφανίζονται **εκείνη τη στιγμή** στον πίνακα (δηλαδή με τα τρέχοντα φίλτρα).

Ανοίγει νέο παράθυρο με την αναφορά και αυτόματα ο διάλογος εκτύπωσης.

**Περιεχόμενο αναφοράς:**

| Ενότητα | Περιγραφή |
|---------|-----------|
| **Κεφαλίδα** | Τίτλος "Family FiN — Αναφορά Κινήσεων", ημ/νία & ώρα δημιουργίας, αριθμός κινήσεων |
| **Φίλτρα** | Chips που δείχνουν τον μήνα, λογαριασμό, κατηγορία και όρο αναζήτησης |
| **Σύνοψη** | Έσοδα / Έξοδα / Υπόλοιπο (ίδια λογική με τη γραμμή σύνοψης της σελίδας) |
| **Πίνακας** | Ημερομηνία, Περιγραφή, Κατηγορία, Λογαριασμός, Ποσό (χρωματιστό), Τακτοποίηση |
| **Υποσέλιδο** | Έκδοση εφαρμογής και σύνολα |

**Χρήση:**
- **Εκτύπωση σε χαρτί:** Πατήστε "🖨️ Εκτύπωση / Αποθήκευση PDF" στο παράθυρο της αναφοράς
- **Αποθήκευση ως PDF:** Στο διάλογο εκτύπωσης επιλέξτε "Αποθήκευση ως PDF" (Chrome) ή "PDF → Αποθήκευση ως PDF" (Safari)
- **Αποστολή με email:** macOS → Share → Mail (από το παράθυρο preview)

> ℹ️ Αν ο browser μπλοκάρει το νέο παράθυρο, επιτρέψτε τα pop-ups για τη διεύθυνση της εφαρμογής.

## 7. Πιστωτικές Κάρτες

Αναλυτική προβολή ανά πιστωτική κάρτα.

### 7.1 Επιλογή κάρτας

Στην κορυφή της σελίδας εμφανίζονται **tabs** για κάθε κάρτα που έχει οριστεί στις Ρυθμίσεις. Πατήστε tab για εναλλαγή κάρτας:
- **VISA** — σκούρο μπλε tab
- **MASTERCARD** — σκούρο κόκκινο tab

### 7.2 Σύνοψη κάρτας

Για την επιλεγμένη κάρτα:
- **Τρέχον Υπόλοιπο:** Κινήσεις του **επιλεγμένου μήνα** (φίλτρο) + μηνιαίες δόσεις — ενημερώνεται αυτόματα όταν αλλάζετε τον μήνα
- **Μηνιαίες Δόσεις:** Σύνολο ενεργών & μη-ολοκληρωμένων δόσεων (/μήνα)
- **Μηνιαίες Κινήσεις:** Κινήσεις του επιλεγμένου μήνα (ίδιο με τον πίνακα από κάτω)

**Κουμπί Πληρωμής:** Κάτω από το Τρέχον Υπόλοιπο εμφανίζεται το κουμπί **💳 Πληρωμή**. Πατώντας το, ανοίγει η φόρμα νέας κίνησης προσυμπληρωμένη με:
- Τύπος: Έξοδο
- Ημερομηνία: Σήμερα
- Ποσό: Τρέχον υπόλοιπο κάρτας (κινήσεις + δόσεις)
- Περιγραφή: "Πληρωμή [Όνομα Κάρτας]"
- Κατηγορία: "Κάρτες" (αν υπάρχει στις κατηγορίες)

Αρκεί να επιλέξετε τον λογαριασμό και να αποθηκεύσετε.

### 7.3 Δόσεις κάρτας

Εμφανίζονται οι ενεργές δόσεις για την επιλεγμένη κάρτα με:
- Γραμμή προόδου (%)
- Αριθμός δόσεων που πληρώθηκαν / σύνολο
- Εναπομένουσες δόσεις
- Μηνιαίο ποσό

Όταν μια δόση **ολοκληρωθεί** (πληρωθούν όλες οι δόσεις), παραμένει ορατή στη λίστα με πράσινο στυλ και "**0 εναπομένουν**" — το κουμπί "+1 Δόση" εξαφανίζεται. Η δόση **δεν συμπεριλαμβάνεται πλέον** στους υπολογισμούς υπολοίπων. Για να αφαιρεθεί εντελώς, πατήστε 🗑️.

**Προσθήκη δόσης:** Πατήστε **"+ Προσθήκη"** (βλ. Ενότητα 8).

### 7.4 Κινήσεις κάρτας

Λίστα κινήσεων της κάρτας, ταξινομημένες κατά ημερομηνία (πιο πρόσφατες πρώτα).

**Φίλτρο μήνα:** Επάνω από τη λίστα υπάρχει επιλογέας μήνα (προεπιλογή: τρέχων μήνας). Αλλάζοντας τον μήνα εμφανίζονται μόνο οι κινήσεις εκείνου του μήνα.

**Προσθήκη κίνησης κάρτας:** Πατήστε **"+ Κίνηση"** και συμπληρώστε:
- Ημερομηνία, ποσό, περιγραφή, κατηγορία

> 📌 Κινήσεις που δημιουργήθηκαν αυτόματα από **Συνδρομές** εμφανίζονται με το εικονίδιο 🔄.

**Desktop — Ενέργειες κίνησης:**
- **✏️** — Ανοίγει τη φόρμα επεξεργασίας (ημερομηνία, ποσό, περιγραφή, κατηγορία)
- **🗑️** — Ζητά επιβεβαίωση και διαγράφει — αν η κίνηση ανήκει σε συνδρομή, **αποτρέπει** την αυτόματη επανεμφάνισή της

**Κινητό** (πάτημα σε γραμμή κίνησης κάρτας):
- Ανοίγει menu ενεργειών με επιλογές **Επεξεργασία** και **Διαγραφή**

## 8. Δόσεις

## 9. Συνδρομές

Διαχείριση **μηνιαίων και ετήσιων συνδρομών** με αυτόματη δημιουργία κινήσεων.

### 9.1 Σύνοψη κόστους

- **Μηνιαία:** Σύνολο μηνιαίων συνδρομών (ετήσιες ÷ 12)
- **Ετήσια:** Συνολικό ετήσιο κόστος όλων των συνδρομών

### 9.2 Προσθήκη νέας συνδρομής

Πατήστε **"+ Νέα Συνδρομή"** και συμπληρώστε:

| Πεδίο | Περιγραφή |
|-------|-----------|
| **Υπηρεσία** | Όνομα (π.χ. "Netflix") |
| **Εικονίδιο** | Emoji για οπτική αναγνώριση (π.χ. 🎬) |
| **Ποσό (€)** | Κόστος ανά περίοδο χρέωσης |
| **Συχνότητα** | Μηνιαία ή Ετήσια |
| **Κάρτα/Λογαριασμός** | Πού χρεώνεται |
| **Ημέρα χρέωσης** | Ημέρα του μήνα (1–31) |
| **Κατηγορία Εξόδου** | Κατηγορία που μεταφέρεται στις κινήσεις |
| **Σε Παύση** | Αν είναι ενεργό, η αυτόματη δημιουργία κινήσεων αναστέλλεται |

### 9.3 Αυτόματη δημιουργία κινήσεων

Κάθε συνδρομή **δημιουργεί αυτόματα** κινήσεις για κάθε μήνα:
- Αν η συνδρομή χρεώνεται σε **κάρτα** → δημιουργείται κίνηση στις Κινήσεις Κάρτας
- Αν χρεώνεται σε **λογαριασμό** → δημιουργείται κίνηση στις Κινήσεις Λογαριασμού

Η αυτόματη δημιουργία εκτελείται **κατά κάθε άνοιγμα της εφαρμογής**, καλύπτοντας αναδρομικά όλους τους μήνες από τη δημιουργία της συνδρομής έως σήμερα. Οι αυτόματες κινήσεις αναγνωρίζονται από το εικονίδιο 🔄. Αν διαγράψετε μια τέτοια κίνηση, **δεν** ξαναεμφανίζεται αυτόματα για τον ίδιο μήνα.

> 💡 Αλλάζοντας την **κατηγορία** μιας συνδρομής, ενημερώνονται αυτόματα **όλες οι υπάρχουσες** αυτόματες κινήσεις της.

### 9.4 Δημιουργία κίνησης επόμενου μήνα

Κάθε κάρτα συνδρομής εμφανίζει το κουμπί **📅 +1** (εμφανίζεται με hover ή πάντα σε κινητό). Πατώντας το:
- Δημιουργείται αμέσως η κίνηση της συνδρομής για τον **επόμενο μήνα** (μόνο αυτόν)
- Αν η κίνηση υπάρχει ήδη, εμφανίζεται σχετικό μήνυμα χωρίς να δημιουργηθεί διπλότυπο
- Χρήσιμο για να έχετε **πλήρη εικόνα μελλοντικών υπολοίπων** πριν κλείσει ο μήνας

### 9.5 Παύση Συνδρομής

Στην επεξεργασία μιας συνδρομής υπάρχει η επιλογή **"Σε Παύση"**:
- Όσο είναι ενεργή, **δεν δημιουργούνται** αυτόματες κινήσεις για τους επόμενους μήνες
- Η συνδρομή παραμένει στη λίστα με οπτική ένδειξη **⏸ Παύση** (αμυδρή εμφάνιση)
- Όταν αποεπιλεγεί, η αυτόματη δημιουργία κινήσεων επαναλαμβάνεται κανονικά

> ℹ️ Χρήσιμο για συνδρομές που έχουν προσωρινά ανασταλεί (π.χ. streaming service σε pause).

### 9.6 Ενέργειες συνδρομής

- **✏️** — Επεξεργασία
- **🗑️** — Διαγραφή συνδρομής. Οι κινήσεις που έχουν ήδη καταχωρηθεί **παραμένουν** και μετατρέπονται σε κανονικές ανεξάρτητες κινήσεις

## 10. Ρυθμίσεις

Κεντρική διαμόρφωση της εφαρμογής. **Οι αλλαγές εδώ επηρεάζουν όλες τις ενότητες.**

### 10.1 Λογαριασμοί

Διαχείριση τραπεζικών λογαριασμών και μετρητών.

**Προσθήκη:** Πατήστε **"+ Νέος"**.

Κάθε λογαριασμός έχει:
- **Όνομα** — Το εμφανιζόμενο όνομα (π.χ. "Μισθοδοσίας")
- **Τύπος** — `Τραπεζικός` ή `Μετρητά`
- **Τράπεζα** — Εμφανίζεται μόνο για τραπεζικούς λογαριασμούς (π.χ. "Alpha Bank")
- **Υπόλοιπο** — Τρέχον υπόλοιπο σε €

**Αποθήκευση:** Πατήστε **"Αποθήκευση"** για κάθε λογαριασμό ξεχωριστά.

**Διαγραφή:** Πατήστε **"Διαγραφή"** (εμφανίζεται μόνο αν υπάρχουν περισσότεροι από έναν λογαριασμός).

> ⚠️ Αλλάζοντας το υπόλοιπο λογαριασμού, ενημερώνεται αμέσως η Γρήγορη Ματιά.

### 10.2 Κάρτες

Διαχείριση πιστωτικών καρτών.

**Προσθήκη νέας κάρτας:** Πατήστε το κουμπί **"+ Νέα"** στην επικεφαλίδα της ενότητας. Δημιουργείται νέα κάρτα με προεπιλεγμένο όνομα την οποία μπορείτε να επεξεργαστείτε αμέσως.

Κάθε κάρτα έχει:
- **Όνομα** — Εμφανιζόμενο όνομα (π.χ. "VISA Gold")
- **Τράπεζα** — Εκδούσα τράπεζα (π.χ. "Alpha Bank")
- **Συνδεδεμένος Λογαριασμός** — Λογαριασμός από τον οποίο γίνεται η εξόφληση της κάρτας

**Αποθήκευση:** Πατήστε **"Αποθήκευση"** μετά από κάθε αλλαγή.

**Διαγραφή:** Πατήστε **"🗑️ Διαγραφή"**. Αν η κάρτα έχει συνδεδεμένες κινήσεις, δόσεις ή συνδρομές, το σύστημα σας ενημερώνει και τα διαγράφει όλα μαζί μετά από επιβεβαίωση.

Οι κάρτες εμφανίζονται ως **tabs** στη σελίδα Πιστωτικών Καρτών.

### 10.3 Κατηγορίες Εξόδων

Λίστα κατηγοριών που χρησιμοποιούνται στις κινήσεις τύπου **Έξοδο**, στις δόσεις και στις συνδρομές.

**Προσθήκη:** Πληκτρολογήστε όνομα στο πεδίο και πατήστε **"Προσθήκη"** (ή Enter).

**Διαγραφή:** Πατήστε το **✕** δίπλα στην κατηγορία.

> ℹ️ Οι προκαθορισμένες κατηγορίες περιλαμβάνουν: Σούπερ μάρκετ, Εστιατόριο/Καφέ, Μεταφορές, Υγεία, Ρουχισμός, Ηλεκτρονικά, Ψυχαγωγία, Τηλεπικοινωνίες, Ενέργεια/Νερό, Ενοίκιο, Ασφάλειες, Δάνειο, Παιδιά κ.ά.

### 10.4 Κατηγορίες Εσόδων

Λίστα κατηγοριών για κινήσεις τύπου **Έσοδο**.

Λειτουργεί ακριβώς όπως οι Κατηγορίες Εξόδων.

> ℹ️ Προκαθορισμένες: Μισθός, Ελεύθερος Επαγγελματίας, Σύνταξη, Ενοίκιο (είσπραξη), Επίδομα, Άλλο.

### 10.5 Ειδοποιήσεις

Διαχείριση των browser notifications για εκκρεμή έξοδα.

**Κατάσταση:** Εμφανίζεται η τρέχουσα άδεια του browser:
- 🟢 **Ενεργοποιημένες** — Οι ειδοποιήσεις λειτουργούν κανονικά
- 🔴 **Απενεργοποιημένες** — Ο browser τις έχει αποκλείσει (απαιτεί αλλαγή από τις ρυθμίσεις του browser)
- 🟡 **Δεν έχουν ρυθμιστεί** — Δεν έχει δοθεί απόφαση ακόμα

**Ενεργοποίηση:** Πατήστε **"Ενεργοποίηση"** — ο browser θα ζητήσει άδεια.

**Δοκιμή:** Μόλις ενεργοποιηθούν, εμφανίζεται κουμπί **"Δοκιμαστική Ειδοποίηση"** για επαλήθευση.

#### Πώς λειτουργούν

- **Κάθε φορά που ανοίγετε την εφαρμογή**, αν υπάρχουν εκκρεμή έξοδα (μη-ολοκληρωμένα, με ημερομηνία ≤ σήμερα), αποστέλλεται **μία** ειδοποίηση την ημέρα
- **Κόκκινος αριθμός (badge)** εμφανίζεται δίπλα στην ενότητα **Κινήσεις** στο μενού, δείχνοντας τον αριθμό εκκρεμών εξόδων
- Αν δεν υπάρχουν εκκρεμή, δεν αποστέλλεται ειδοποίηση και το badge δεν εμφανίζεται

> ℹ️ Αν κλείσετε το banner ενεργοποίησης με **"Αργότερα"**, μπορείτε να ενεργοποιήσετε τις ειδοποιήσεις αργότερα από εδώ.

## Παράρτημα — Λογική Υπολογισμών

### Πρόβλεψη Υπολοίπου Λογαριασμού

```
Πρόβλεψη Υπολοίπου = Τρέχον Υπόλοιπο
                     + Σύνολο Εσόδων (όλες οι μελλοντικές κινήσεις)
                     − Σύνολο Εξόδων (όλες οι μελλοντικές κινήσεις)
```

Λαμβάνονται υπόψη **όλες** οι καταχωρημένες κινήσεις ανεξαρτήτως ημερομηνίας, με ανώτατο όριο το τέλος του επόμενου μήνα.

### Σύνολο Κάρτας (Dashboard)

```
Σύνολο Κάρτας (μήνα) = Κινήσεις τρέχοντος μήνα
                      + Μηνιαίες δόσεις (ενεργές & μη-ολοκληρωμένες)
```

### Γράφημα Εξόδων ανά Κατηγορία

Συνυπολογίζει για τον **τρέχοντα μήνα**:
1. Κινήσεις τύπου Έξοδο (εκτός κατηγορίας "Κάρτες")
2. Κινήσεις πιστωτικών καρτών
3. Μηνιαίο ποσό ενεργών δόσεων (με την κατηγορία τους)
